# Декомпозиция командного режима на минимальные части
1. Генератор кода сессии (1 SP):
   - Создание уникального 4-значного числового кода комнаты при нажатии «Создать команду».
   - Зависимости: нет.

2. Модуль подключения по коду (1 SP):
   - Поле ввода кода для подключающихся игроков и валидация кода сессии.
   - Зависимости: зависит от Генератора кода сессии.

3. Единый счётчик очков команды (1 SP):
   - Связывание баллов за ответы участников с ID текущей сессии комнаты. Начисление очков в общую копилку.
   - Зависимости: зависит от Модуля подключения и функции проверки ответа.

Граница MVP: Чат, личные сообщения, роли игроков, приглашения по прямой ссылке и push-уведомления НЕ входят в минимальный вариант.
