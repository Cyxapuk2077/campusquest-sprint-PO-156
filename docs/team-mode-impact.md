# Влияние командного режима на Спринт 3
- **Оценка:** 3 SP.
- **Влияние на Sprint 1:** Требует изменения архитектуры хранения сессий (добавление сущности "Команда" и единого ID сессии).
- **Решение:** Берем минимальный вариант сейчас.
- **Баланс SP:** Было 16 SP. Чтобы включить командный режим (3 SP) и не превысить жесткий лимит в 18 SP, из бэклога переносится функция CQ2 "Имя и аватар игрока" (2 SP) в следующий спринт. Новая сумма составляет 17 SP (16 - 2 + 3 = 17 SP <= 18 SP).
