# Сценарий использования командного режима (до 4 игроков)
1. Создать команду: Игрок на главном экране нажимает «Создать команду». Система генерирует уникальную сессию.
2. Получить код: На экране создателя появляется 4-значный уникальный код комнаты и список подключенных участников.
3. Присоединиться по коду: Остальные игроки (до 3 человек) выбирают «Присоединиться», вводят 4-значный код. При вводе неверного кода система выводит ошибку «Код не найден» и просит повторить ввод. При успехе игроки добавляются в список.
4. Пройти станцию и отправить ответ: Команда вместе читает задание станции. Любой из участников команды может ввести ответ в текстовое поле и нажать «Отправить».
5. Общий счёт: При правильном ответе баллы начисляются в один общий счёт всей команды, который отображается на экранах всех участников сессии.
