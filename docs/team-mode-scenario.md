# Сценарий командного режима (до 4 игроков)
1. **Создание:** Игрок А нажимает "Создать команду", получает 4-значный код.
2. **Сбор:** Игроки Б, В, Г вводят код и присоединяются.
3. **Игра:** Команда переходит на станцию. Любой участник вводит ответ.
4. **Счет:** При верном ответе баллы начисляются на общий счет команды.
5. **Финал:** При завершении квеста выводится общий результат команды
