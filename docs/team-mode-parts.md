# Декомпозиция командного режима на 3 части
1. **Менеджер комнат (Backend):** Генерация уникального кода, хранение списка участников (макс. 4).
2. **UI подключения (Frontend):** Экран ввода кода, отображение состава команды, кнопка "Старт".
3. **Синхронизация ответов (Backend+Frontend):** Привязка отправленного ответа к ID команды, пересчет общего счета.
