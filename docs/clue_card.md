НАЗВАНИЕ ФУНКЦИИ: Поле для ответа и проверка (CQ5, CQ6)

ЗАЧЕМ НУЖНА: Обеспечивает интерактивный ввод решения пользователем и мгновенную обратную связь системы.

СЦЕНАРИЙ ИГРОКА: 
1) Игрок вводит свой вариант ответа в специальное текстовое поле.
2) Нажимает кнопку «Проверить».
3) Система сравнивает ответ и выводит экран/сообщение «Верно» или «Попробуй ещё».

КРИТЕРИИ ГОТОВНОСТИ: 
- Поле ввода корректно принимает текстовые символы и очищается при необходимости.
- Проверка ответа происходит без перезагрузки страницы (регистронезависимо).
- Выводится четкое визуальное сообщение с результатом проверки.
